# How to run Leg_Test

1. Create virtual environment (optional)

    ```bash
    python3 -m venv venv
    ```

2. Install packages:

    ```bash
    pip3 install numpy scipy sympy pyserial matplotlib
    ```

3. Install PyBEAR. Navigate to /PyBEAR and enter:

    ```bash
    python3 setup.py install
    ```
